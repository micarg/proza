# Proza

Απλός επεξεργαστής σεναρίου για σειρές. Ανοίγει στο https://micarg.github.io/proza/ και μπαίνει στην οθόνη Αφετηρίας του iPhone (Safari → Κοινοποίηση → Προσθήκη στην οθόνη Αφετηρίας).

Τα κείμενα αποθηκεύονται μόνο στη συσκευή. Κράτα αντίγραφα ασφαλείας από το μενού.

Το λεξικό αυτόματης διόρθωσης βασίζεται στη λίστα συχνότητας λέξεων FrequencyWords (hermitdave). Η γραμματοσειρά Cousine διανέμεται με άδεια SIL Open Font License.
