Ρυθμίσεις

Αλλάζει μόνο την οθόνη. Το PDF και η προεπισκόπηση μένουν σε κλασική γραμματοσειρά σεναρίου.

Διορθώνει και βάζει τόνους όταν πατάς κενό. Αν μια διόρθωση δεν σου αρέσει, πάτα αμέσως διαγραφή για να επανέλθει η λέξη σου. Θα σε ρωτήσει αν θέλεις να μπει στο λεξιλόγιο.

Συντομεύσεις

Τρία κενά βάζουν κόμμα.

Όταν γράφεις όνομα ή σκηνή, εμφανίζεται αχνά η συνέχεια. Πάτα πάνω της για να συμπληρωθεί.

Πάτα στην οθόνη όσο γράφεις για να εμφανιστούν τα κουμπιά.

Το μικρό εικονίδιο δεξιά από κάθε σκηνή ανοίγει σημειώσεις και σύνοψη, που δεν τυπώνονται.

Enter πηγαίνει στο επόμενο: Σκηνή → Δράση → Χαρακτήρας → Διάλογος → Δράση → … Διπλό Enter ξεκινά νέα σκηνή.

Γράψε ΕΣΩΤ. ή ΕΞΩΤ. και η γραμμή γίνεται σκηνή. Γράψε ( στην αρχή διαλόγου για παρένθεση.

Στον υπολογιστή: Tab αλλάζει τύπο, Ctrl+1…6 για κάθε τύπο.

Αυτή είναι μια σκηνή-παράδειγμα για να δεις πώς δουλεύει.
Έχεις αλλαγές χωρίς αντίγραφο ασφαλείας.
